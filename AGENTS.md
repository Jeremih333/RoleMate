# Правила работы с RoleMate

- TypeScript всегда компилируется со `strict: true`; обходы через `any` запрещены.
- `apps/bot-api` не выполняет SQL и обращается к D1 только через подписанный Worker API.
- Worker принимает только заранее определённые операции с Zod-валидацией и prepared statements.
- Миграции последовательны, неизменяемы после применения и сначала проверяются на preview.
- Нельзя удалять данные миграцией без плана резервного копирования и восстановления.
- Для цифрового Premium внутри Telegram разрешён только Telegram Stars (`XTR`).
- YooKassa и рублёвые методы нельзя включать для Telegram Premium.
- Единственный superadmin имеет Telegram ID `1040929628`; ID берётся только из
  проверенной server-side Telegram-сессии.
- Пользовательские системные тексты хранятся в `packages/shared/src/locales/ru.ts`.
- В основных информационных разделах используется подпись
  «Создано при поддержке пиар-чата @piarchaticksss».
- Нельзя пересылать анонимные сообщения методом forward или логировать их полный текст.
- Новая функциональность требует unit/integration тестов; исправление ошибки —
  regression test.
- Задача не считается завершённой без фактических lint, typecheck, tests, build,
  security scan и честного `FINAL_VERIFICATION_REPORT.md`.
