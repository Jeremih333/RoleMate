# RoleMate toolkit

Локальные инструменты, созданные до начала реализации проекта и используемые
для воспроизводимой разработки и проверки.

## Инструменты

- `read-utf8.ps1` — читает UTF-8 файлы без искажения кириллицы.
- `extract-markdown-section.ps1` — извлекает раздел большого Markdown-ТЗ по заголовку.
- `repo-audit.ps1` — фиксирует структуру репозитория, версии среды и состояние Git.
- `secret-scan.ps1` — ищет случайно добавленные секреты, не печатая их значения.
- `verify.ps1` — запускает доступные проверки проекта единым проходом.

Все скрипты завершаются ненулевым кодом при обнаружении ошибки и подходят для
локального запуска и CI.
